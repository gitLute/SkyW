Часть решений нельзя принять без владельца проекта. До их решения
реализация может идти только в части, которая от них не зависит.
Решения по ядру и их обоснование — `docs/pending_architecture.md`.

| Вопрос | Ответ |
|---|---|
| Целевая платформа и бюджет кадра | Linux + Windows; бюджет кадра не задан |
| Фиксированный шаг симуляции по умолчанию | Да, 60 Hz; значение настраивается |
| Максимум потоков | Две полосы ядра: выходная и симуляция, или одна в однопоточном режиме. Подсистема вправе держать свои потоки внутри реализации (Jolt, звук) |
| Язык скриптов | собственный скрипт |
| Требуется ли горячая перезагрузка сцен | Скорее нет |
| Единицы измерения | Метры |
| Состав ядра | Обязателен только ECS; Silk, Jolt и звук подключаются позже адаптерами |
| Состояние sim→render | Keyframe и SoA-дельты, рендер держит зеркало |
| Ёмкость канала состояния | Кольцо преаллоцированных арен, число и размер задаются конфигурацией; буфер keyframe отдельный, негабарит — фатальная ошибка |
| Перегрузка симуляции | Slow-mo: шаги не теряются, растёт долг; порог долга (по умолчанию 2 с) — сброс с ошибкой в журнал |
| Ошибки рантайма | Fail-fast: исключение в стадии останавливает движок с отчётом |
| Порядок стадий шага | Логика → физика → синхронизация → публикация |
| Ввод | Очередь событий с монотонными штампами, шаг забирает по дедлайну |
| Точка входа | Build → Start → Loop → Stop; `IEngine` со `Step()` |
| Формат дельт | SoA-массивы по зарегистрированным типам |
| Изменение компонентов | Значение в обходе — `ref` плюс явный `MarkChanged<T>`; значение, добавление и снятие вне обхода — `Set`/`Remove`; структура — очередь команд |
| Создание сущностей | Только через инстанциацию префаба командой `Spawn`; у систем и поведений метода создания нет |
| Префабы | Исполняемые определения на skywscript того же типа, что генератор сцены; Build печёт в программу создания, спавн воспроизводит с оверрайдами |
| Права генератора сцены | Builder с полными правами: создание узлов, компоненты, вызовы префабов; запросов к миру нет |
| Деспавн | Экземпляр — корень и поддерево; `Despawn` удаляет всё поддерево |
| Интерполяция | Флаг «непрерывный» у типа, пара prev/current в зеркале, alpha не больше 1 |
