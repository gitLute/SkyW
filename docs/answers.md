Часть решений нельзя принять без владельца проекта. До их решения
реализация может идти только в части, которая от них не зависит.

| Вопрос | Ответ |
|---|---|
| Целевая платформа и бюджет кадра | Linux + Windows |
| Фиксированный шаг симуляции по умолчанию | Да |
| Максимум потоков | Нет 2 (1 рендер, 1 сервер) или 1 для однопатока |
| Язык скриптов | собственный скрипт |
| Требуется ли горячая перезагрузка сцен | Скорее нет |
| Единицы измерения | Метры |
| Объём кольцевого буфера | 3 слота |
