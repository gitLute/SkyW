# Файлы правил для агентов и каталог журнала

Дата: 2026-10-13
Ветка: main

## Задача

Описать в корне репозитория `AGENTS.md` — правила работы ИИ-агентов —
и завести каталог `log/` для коротких отчётов и заметок.

## Что сделано

- `AGENTS.md` — три главных правила (комментарии по делу, доводить задачу
  до идеала, писать отчёты в `log/`), команды сборки и тестов, архитектурные
  ограничения, формат журнала, правила работы в команде, таблица частых ошибок.
- `log/README.md` — формат отчёта и заметок с примером.
- `.gitignore` — в конец добавлено `!log/` и `!log/*.md`: шаблон VisualStudio
  содержит `[Ll]og/` (строка 47) и иначе каталог не версионируется.

## Проверка

- `dotnet build SkyW.slnx -c Release` — 0 ошибок, 0 предупреждений, 10 с.
- `dotnet test --solution SkyW.slnx` — `total: 59`, `failed: 0`, `succeeded: 59`.
- Команды и утверждения сверены с `README.md`, `docs/engine-architecture.md`,
  `docs/stack-constraints.md`, `docs/answers.md`, `global.json` и
  `Directory.Build.props`.

## Открытые вопросы

- `dotnet test --solution SkyW.slnx` завершается кодом 8, потому что
  `SkyW.Tests.Stack` и `SkyW.Tests.Architecture` пусты. `README.md` называет
  это «тестов ещё нет», но для CI-гейта по коду возврата это провал. Нужно
  решение владельца: написать тесты или считать вердикт по `failed: 0`.
- Проверки графа ссылок в `SkyW.Tests.Architecture` нет: правило слоёв
  (раздел 4 `AGENTS.md`) держится только на договорённости.

## Дальше

Первыми задачами разумно взять тесты `SkyW.Tests.Architecture` (проверка
направления зависимостей) и `SkyW.Tests.Stack` (регрессия `Foundation.Init`),
чтобы ограничения из документа проверялись машиной.
