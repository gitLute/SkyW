# log/

Рабочие отчёты и заметки ИИ-агентов по репозиторию SkyW.

Правила ведения журнала — в `AGENTS.md`, раздел 5 и раздел 1.2.
Каталог общий для команды: файлы не переписываются и не удаляются,
это история принятых решений.

## Имена файлов

| Файл | Что внутри |
|---|---|
| `log/YYYY-MM-DD-задача.md` | отчёт по завершённой задаче |
| `log/YYYY-MM-DD-задача-notes.md` | заметки по ходу работы |

Имя задачи — короткое, латиницей, через дефис:
`log/2026-10-13-ring-buffer-log-sink.md`.

## Отчёт

Пять блоков, каждый — несколько строк:

```markdown
# Кольцевой буфер приёмника журнала

Дата: 2026-10-13
Ветка: feature/ring-buffer-log-sink

## Задача

Приёмник, который хранит последние N сообщений в памяти, чтобы оверлей
показывал их без чтения файла.

## Что сделано

- `src/SkyW.Diagnostics/Logging/RingBufferLogSink.cs` — приёмник, без блокировок.
- `tests/SkyW.Tests.Unit/Logging/RingBufferLogSinkTests.cs` — 6 тестов.

## Проверка

- `dotnet build SkyW.slnx -c Release` — без предупреждений.
- `dotnet test --solution SkyW.slnx` — 24 теста пройдено.
- Замер: 1 млн записей, 38 мс до / 35 мс после (профилирование не ухудшилось).

## Открытые вопросы

Ёмкость по умолчанию 3 слота взята из `docs/answers.md`; если владелец
проекта пересмотрит решение, значение меняется одной константой.

## Дальше

Подключить буфер к оверлелю в `src/SkyW.Rendering`.
```

## Заметки по ходу работы

Короткие, по одной записи на смысловой шаг: что проверил, что удивило,
какое решение принял и почему. Без дампов логов и листингов кода — только
выводы, числа и ссылки на документы.

```markdown
# Заметки: кольцевой буфер приёмника

Дата: 2026-10-13

- Синхронизация выбрана простой блокировкой на запись, а не безблокировочной
  очередью: приёмник пишет из одного потока, читается из рендер-потока.
- Jolt на месте не мешает: приёмник не трогает физику
  (docs/stack-constraints.md раздел 2).
```

## Чего в `log/` не пишут

- Полных логов сборки и тестов: достаточно вывода команды и итоговых чисел.
- Листингов кода: отчёт описывает решение, код лежит в коммите.
- Пересказов `docs/` и `AGENTS.md`: достаточно ссылки на раздел.
